What comes when. Work after M7 ships as small packages: player packages run by day, go to the test app and get one short playtest; engine packages run headless at night. [STATUS](STATUS.md) holds each package's state, the blueprint holds design scope ([§7](blueprint.md#7-milestones-and-exit-criteria)), the [packages design](superpowers/specs/2026-11-11-packages-and-playtest-helper-design.md) holds the rules.
