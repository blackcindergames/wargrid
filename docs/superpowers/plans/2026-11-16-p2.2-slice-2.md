**Goal:** The result panel shows match length and per-player units built, units lost and buildings lost from simulation counters that are never hashed; an opponent who leaves mid-match gives the stayer a Victory panel (F27); the online leave confirmation says what leaving means; the launcher gets default focus, a focus outline picked in an A/B, 32 px targets, a 12 px Tag, Quit and a "Match code" label; a `left-mid` netplay scenario; then test-app playtest and production release.

**Architecture:** `Simulation` keeps a `_match_stats` dictionary beside `_players` (never in `snapshot()`, so `StateHash.digest`, the hash ring and every trace stay unchanged), incremented where production spawns a unit and at the three death sites plus the tunnel bury; `match_stats()` is the new read. `Lockstep.opponent_left()` is the one opponent-left rule, used by the online driver and the headless client. `Hud._match_hud` passes rows built from `driver.sim.match_stats()` and a length line into `ResultPanel.show_result`, which stays a pure view.

**Tech Stack:** Godot 4.7.2 typed GDScript, suite runner `game/tests/run_tests.gd`, POSIX sh tools. No Go, relay or protocol change.

## Same-tick interactions

No new commands: the counters react to existing code paths, and the command table in the sim interface is unchanged. The step order (`simulation.gd` `step`: `_apply_orders`, `Construction.step`, `RebuildHoles.step`, `Production.step`, …, `Combat.fire`, `Combat.fire_defences`, `_evaluate_match`) fixes these cases:

| Case | Expected | Test |
|---|---|---|
| unit produced on tick T (production runs after `Combat.plan`, so it is not targeted that tick) | built on T, never lost on T | MS2 |
| building completes and is destroyed on the same tick (construction runs before combat) | `buildings_lost` +1; its `spawns_on_complete` unit is not built | MS9 |
| last tunnel hub and an outside unit die in one volley; the bury removes the occupants | hub +1 building, outside unit +1, each occupant and rider +1, nothing twice | MS8 |
| transport destroyed with passengers; release damage kills some | each dead passenger +1, survivors 0, transport +1 | MS7 |
| `cancel_production` on the tick the entry would complete (orders apply first) | not built | MS3 |
| `cancel_build` of a site; a site destroyed by combat | no `buildings_lost` | MS6 |
| `remove_object` of a unit or building (test-only path) | not lost; occupants buried by it do count (the bury rule) | MS5, MS8 |
| peer's `left` whose `after_tick` is the tick the simulation ends the match | normal outcome, `opponent_left()` false | L17 |
| peer leaves mid-match | `ended_left`, Victory, stats frozen at the last stepped tick | N29 |

  - `func match_stats() -> Array[Dictionary]`: one new dictionary per player in ascending id order, `{"player": id, "units_built": n, "units_lost": n, "buildings_lost": n}`.
  - `func _count_built(owner: int, count: int) -> void`; `func _count_death(id: int) -> void`: a unit in `_entities` adds 1 to its owner's `units_lost`; a building in `_buildings` with `completed` and without the `rebuild` key (the hole marker) adds 1 to `buildings_lost`; an owner without a row is ignored. - Call sites:
  - `production.gd` `step`, before → after:
    ```gdscript
    		var spawned: int = spawn_unit(sim,building,entry.kind,occupied)
    		if spawned != -1: building.queue.pop_front()
    ```
    ```gdscript
    		var spawned: int = spawn_unit(sim,building,entry.kind,occupied)
    		if spawned == -1: continue
    		building.queue.pop_front()
    		sim._count_built(building.owner,Registry.kind(entry.kind).get("quantity",1))
    ```
    (`spawn_unit` places all `quantity` units or none, because `free_exits` checks the same cells `spawn` does; `_spawn_on_complete`, `RebuildHoles._spawn_worker` and `MapData` start units do not pass here.)
  - `combat.gd` `fire` and `fire_defences`: `sim._count_death(id)` / `sim._count_death(target)` after the `record(...).is_empty(): continue` guard and before the `death` event.
  - `containers.gd` `_release`: `sim._count_death(id)` before its `death` event; `_bury`: `sim._count_death(rider)` before each rider's `remove_object`, `sim._count_death(id)` before the occupant's.
