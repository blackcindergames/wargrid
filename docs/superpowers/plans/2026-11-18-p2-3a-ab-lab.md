# P2.3a A/B Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Four new questions in the art lab (token set A against B side by side, health-bar rule, value size 13 against 14, drag box) on a frozen 120-unit army drawn in the round 6 look, a lab-only HUD v5 panel, offscreen captures and an outside-repo click page, so the owner picks all four in one attended window session tonight.

**Architecture:** All new code lives in `game/scripts/lab/`. A lab subclass of the world view (`lab_view.gd`) draws bodies in palette A without touching `palette.gd`; the lab feeds the view a copy of the snapshot with full health and no selection, so production marks and bars never draw, and lab overlays draw the white marks, hover ticks, framed bars, map edge B and the drag box. A small controller node (`selection_lab.gd`) owns the frozen army, the panel and the new keys; `art_lab.gd` hands it the four new questions.

**Tech Stack:** Godot 4.7.2, typed GDScript, the repo test runner (`tools/run_tests.sh`), Python 3 for one docs table, `tools/serve_web_bench.py` for the click page.

**Spec:** `docs/superpowers/specs/2026-11-18-p2-3a-ab-lab-design.md` (approved by the user 2026-11-18). Inputs: `docs/reference/hud-v5-layout.md`, `docs/images/hud-v5/source/hud.js` and `hud.css`, `docs/reference/map-art-shapes.md` §"P2.3a See your selection" and the Palette A table, `docs/reference/art-lab-verification.md`.
