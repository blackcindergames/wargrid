# P2.2 Quick rematch, slice 1: Implementation Plan

**Status:** approved; the user started the unattended run on 2026-11-15 (daytime night run, handoff `p2.2-quick-rematch-night-prompt.txt`, private).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Run rules: [milestone prompt](../../milestone-prompt.md): one fresh subagent per task, each starting from the resume record in `docs/reference/p2.2-verification.md`.

**Goal:** A lobby that survives minutes of silence and expires after 15 min with "Your friend did not join in time", a 5 s hello deadline, a match start that waits for a hidden host (F11), Play again in the same room after a match, a result panel online and offline, and Enter / elapsed time / Cancel while connecting.

**Architecture:** The relay keeps one goroutine per room and gains phase-aware read deadlines (a small `deadline` type on each `conn`, guarded by a mutex so the room goroutine and the reader never race), a room timer for lobby expiry and the park limit, and two client messages: `over` parks the room once every seat sent it, `again` (echoed with `seat`) restarts it with a new seed. The client relaxes its 5 s silence rule while patient, the online driver keeps the socket after a sim-decided end and builds a new `Lockstep` and `Simulation` when the relay's next `start` arrives, and one code-built `ResultPanel` replaces the HUD's `Result` label and `Restart` button.

**Tech Stack:** Go (relay `relay/`, conformance `protocol/conformance`, Go version in `relay/go.mod`), Godot 4.7.2 typed GDScript, suite runner `game/tests/run_tests.gd`, POSIX sh tools.

**Spec:** [P2.2 slice 1 design](../specs/2026-11-15-p2.2-quick-rematch-design.md) (approved, `78fc363`; every decision is final). Package row: [packages](../../packages.md#day-lane) P2.2.

## Review Focus

1. **Play again pressed twice** (double click, click then Enter): a second `again` is `invalid message` and kills the seat. Exactly one `again` leaves the client. Test in Task 6 (`test_play_again_sends_once`).
2. **The friend's `again` arrives before this client's own end** (it is still catching up the last ticks): today `Lockstep.receive` ends that as `ended_protocol`. It must be kept and shown after the end. Test in Task 6 (`test_friend_again_before_own_end`).
3. **The relay's second `start` and the peer's tick 4 in one poll batch:** the tick must reach the new `Lockstep`, not the parked one. Test in Task 6 (`test_rematch_builds_new_match`).
4. **Enter while the pause menu is open over the result panel** must not restart; Esc keeps opening the pause menu. Test in Task 5 (`test_result_panel_keys`).
5. **A join arriving as the lobby expires:** never both a `start` and `lobby expired` for one room. Test in Task 1 (`TestExpiryRacesJoin`).
6. **An `again` already queued when the park timer wins:** never `room expired` followed by `start`. Test in Task 2 (`TestQueuedAgainAfterExpiry`).
7. **`patient` on the result panel, and `start` plus `left` in one poll:** the panel survives a returning hidden tab; no match is built for a friend who is gone. Tests in Task 6 (`test_patient_holds_on_result_panel`, `test_start_then_left_same_batch`).
