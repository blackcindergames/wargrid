# Esc menu round pictures

Source for the War Room round on the Esc menu (P18, 2026-11-24). `esc.html` draws the in-match menu over `../hud-v5/source/worlds/w-factory.png`, dimmed as the game dims it, with the round's variants as hash or query parameters: `view` (`menu`, `confirm`, `settings`, `controls`), `os` (`mac`, `win`, `web`; `web` is a browser off macOS: no Quit, its own save-group row), `size` (`1280x720`, `1280x800`, `1920x1080`; the game stretches its UI from 1280 x 720 with aspect "expand", so 1920 x 1080 is the 720 layout at 1.5x), `menu` (`plain`, `mouse`, `side`), `controls` (`two`, `three`, `picture`), `settings` (`switch`, `text`, `cols`), `page` (`replace`, `beside`), `focus` (a button name); the defaults are the round's recommendations, and `measure=1` prints the measurement rows on the page. Sizes and colours come from `game/ui/launcher_theme.tres` (HudSmallButton, HudSmallPanel, HudKey, HudLabel, HudTitle, HudHint, the switch icons); the slider is drawn after Godot's default theme. It needs the repository layout (`game/fonts/`); serve it through War Room. The `.webp` files are lossless 2x exports from `sh warroom/tools/shoot.sh`, one per option (`menu-*`, `confirm`, `controls-*`, `settings-*`, `page-*`), at 2560 x 1440 except `controls-two-800` (2560 x 1600) and `controls-two-1080` (3840 x 2160).
