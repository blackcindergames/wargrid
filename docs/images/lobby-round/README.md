# Lobby round pictures

Source for the War Room round on the lobby (P20, 2026-11-26), drawn from the owner's lobby prototype (private). `lobby.html` draws the launcher's Play page and lobby with the round's variants as hash or query parameters: `view` (`play`, `lobby`, `open` waiting for the friend, `s1v1` you vs your friend, `skirmish`, `guest`, `map`, `faction`, `reduce`, `pick` the colour pick), `start` (`cards`, `row`, `two`), `unused` (`rows`, `line`), `slots` (`teams`, `columns`, `flat`), `spot` (`map`, `letter`, `random`), `colour` (`player`, `team`), `invite` (`top`, `footer`, `slot`), `guest` (`readonly`, `disabled`), `picker` (`dialog`, `inline`), `map` (`dry_wells`, `broken_crown`, `ashfall`), `room` (`on`, `off`: the amber dashed boxes where later features go), `size` (`1280x720`, `1280x800`, `1920x1080`; the UI scales from 1280 x 720 as the game does); the defaults are the round's recommendations, and `measure=1` prints the measurement rows on the page. Colours come from `game/ui/launcher_theme.tres` (its Hud set) and `game/scripts/presentation/palette.gd` (OWNER_BASE); maps, starts and supply sources from `game/data/maps/`; emblems from `../launcher-mockups/emblem-*.svg`. It needs the repository layout (`game/fonts/`); serve it through War Room.
