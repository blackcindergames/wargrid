# Lobby look round pictures

Source for the War Room round `lobby-look` (P20, 2026-11-26), derived from `../lobby-round/lobby.html` in the navy look decided after the first bot match. `lobby-look.html` takes hash or query parameters: `view` (step 1: `rest`, `hover`, `press`, `focus`; step 2: `before`, `copied`, `later`, `friend`; step 3: `entry`, `link`, `connecting`, `error`, `full`, `joined`), `remove` (`x`, `red`, `ghost`, `text`), `box` (`owner`, `icon`, `big`, `field`), `entry` (`row`, `body`, `card`), `size` (`1280x720`, `1280x800`, `1920x1080`); the defaults are the round's recommendations, and `measure=1` prints the measurement rows on the page (fit, Mode row width, cut-off text, faction column alignment). `today-rows.webp` and `today-invite.webp` are the owner's screenshots of the slice-1 launcher, `sketch-join.webp` the owner's sketch of the three modes. It needs the repository layout (`game/fonts/`); serve it through War Room.
