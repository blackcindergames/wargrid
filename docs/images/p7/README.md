# P7 part 2 team screens

Source for the advisory War Room round `p7-2-team` (2026-11-24) and the slice's player-experience pass: `team.html` draws the 2v2 screens at a 1280 x 720 layout with hash or query parameters: `view` (`play`, `waiting`, `join`, `match`, `end`, `confirm`), `mode` (`bot`, `friend`, `team`; Play page), `hidden=1` (team path with the remembered map hidden), `busy=1` (Play page locked while connecting), `os` (`mac`, `win`, `web`; the browser has no Quit and an invite link), `state` (`start`, `stall`, `out`, `ping`, `armed`, `mark`; match view), `end` (`victory`, `defeat`, `left`, `host`), `who` (`host`, `guest`, `out`: whose view; the Leave match question of the host, the playing guest and the defeated guest), `set` (`base`, `neon`: the owner colours by viewer, design answers Q4), and `measure=1` prints the measurement rows. The host is P1 USA and the guest P2 China; the match screens show the guest's view except `end=left` and `who=host`. Launcher sizes and colours come from `game/ui/launcher_theme.tres` and `game/scenes/launcher.tscn`; the HUD from the `HudSlab`, `HudChip`, `HudKey` and `HudButtonArmed` styles and [the HUD v5 layout reference](../../reference/hud-v5-layout.md); the confirm box as [the Esc menu round](../esc-round/esc.html) draws it; the result card from `game/scripts/match/result_panel.gd`. The world is plain sand with boxes in the owner colours, so both colour sets draw exactly. It needs the repository layout (`game/fonts/`); serve it through War Room.

The `.webp` files are lossless 2x exports (2560 x 1440) from `sh warroom/tools/shoot.sh '/docs/images/p7/team.html#<params>' <out.webp> 2560x1440`: `play-bot`, `play-friend`, `play-team`, `play-team-hidden`, `play-team-connecting`, `waiting-team`, `join-version`, `match-start`, `match-stall`, `match-out`, `match-ping`, `match-armed`, `match-mark`, `match-mark-neon`, `leave-host`, `leave-guest`, `leave-guest-out`, `end-victory`, `end-victory-neon`, `end-defeat`, `end-left`, `end-host`.
