# Production strip round pictures

Source for the War Room round `production-strip` (P16, 2026-11-23). `strip.html` draws the top strip with the production strip at 1280 x 720 over `../hud-v5/source/worlds/w-factory.png`, with the round's variants as hash or query parameters (`state` = `mixed`, `idle`, `many`, `more`, `low`, `hover`, `card`, `frc`; `chip`, `group`, `idle`, `order`, `cap`, `anchor`; the defaults are the round's recommendations). The panel steps use `../queue-round/factory.html` with its `boxh`, `nextpoint`, `nextrow`, `fx` and `fxa` parameters. Both need the repository layout (`../hud-v5/source/glyphs3.js`, `game/fonts/`); serve them through War Room. The `.webp` files are 2x exports at 2560 x 1440, one per option (`<step>-<letter>`, `anchor-*-card` and `anchor-*-low` for its extras, `rally-b-idle`, `state-*` for the other strip states). `cancel-a.webm` and `cancel-b.webm` are 3 s VP8 clips at 2560 x 1440, cut from `factory.html` frames (`fx=before`, `fx=none`, `fx=flash&fxa=1` to `0.25`) with ffmpeg's concat demuxer.
